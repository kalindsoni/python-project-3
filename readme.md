# 🎓 Student Data Organizer

A simple and beginner-friendly Python CLI application for managing student information.

📌 About the Project

Student Data Organizer is a menu-driven Python application that helps users
manage student information using a Python dictionary.

The application allows users to:

➕ Add student records
👁️ View student details
✏️ Update student information
🗑️ Delete student records
📚 Display subjects offered
🚪 Exit the program
